#  Description
AudioMailr is a full-stack email application that enables users to send, receive, and listen to emails using text-to-speech technology—enhancing accessibility for users with visual impairments or reading difficulties.

🔨 Team Contributions
Backend Development (2 Team Members)

Designed and implemented the Node.js/Express backend, developing RESTful APIs to handle user registration, login, email CRUD operations, and audio file generation.
Set up a MySQL database schema for storing user data, emails, audio file paths, and preferences.
Managed project deployment using GitHub and local hosting environments.
Created and executed test cases (unit & integration) for both frontend and backend components.
Ensured cross-browser compatibility and responsive design testing.

Frontend Development & TTS Integration (2 Team Members)

Built the user interface using React, creating dynamic views for composing, browsing, and organizing emails (Inbox, Sent, Trash).
Integrated text-to-speech playback on the client side, allowing users to convert received email content to audio using browser-based TTS APIs or external libraries.
Developed intuitive UI/UX for audio controls—play, pause, and adjust speed—improving user accessibility and experience.
